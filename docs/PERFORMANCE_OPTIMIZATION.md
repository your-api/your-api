# Your-API 性能优化配置

本文档说明了针对大请求和高并发场景的性能优化配置。

## 1. HTTP客户端优化

### 连接池配置
- **MaxIdleConns**: 500 (原值: 100)
- **MaxIdleConnsPerHost**: 200 (原值: 100)
- **MaxConnsPerHost**: 200 (新增)
- **缓冲区大小**: 读写各64KB (新增)

### 超时优化
- **连接超时**: 30秒 (原值: 60秒)
- **TLS握手超时**: 15秒 (原值: 30秒)
- **响应头超时**: 60秒 (原值: 120秒)

## 2. 流式响应优化

### StreamOptimizer
- 使用64KB的缓冲读取器
- 实现缓冲池复用，减少内存分配
- 支持立即刷新，减少延迟

### 优化效果
- 减少流式响应的延迟
- 降低内存使用
- 提高吞吐量

## 3. 连接池管理

### ConnectionPoolManager
- 每个主机最大200个并发连接
- 自动清理空闲超过5分钟的连接池
- 提供连接获取和释放的并发控制

### 优势
- 防止连接泄漏
- 控制并发请求数
- 优化资源使用

## 4. 大请求优化

### LargeRequestOptimizer
- 自动检测超过50KB的请求
- 优化工具定义，截断过长的描述
- 提供请求大小监控和告警

### 监控阈值
- 大请求警告: 50KB
- 超大请求警告: 100KB

## 5. 异步日志系统

### AsyncLogger
- 10000条日志的缓冲队列
- 100ms批量刷新间隔
- 自动降级保护（队列满时）

### 性能提升
- 减少I/O阻塞
- 批量写入提高效率
- 不影响主请求处理

## 6. 请求缓存

### RequestCache
- 缓存非流式、确定性请求
- 5分钟TTL
- 最多缓存1000个请求

### 缓存策略
- 不缓存流式请求
- 不缓存包含工具的请求
- 不缓存temperature > 0的请求

## 环境变量配置

```bash
# HTTP客户端超时（秒）
RELAY_TIMEOUT=300

# 是否启用调试日志
DEBUG_ENABLED=false

# 流式超时（秒）
STREAMING_TIMEOUT=60

# 连接池大小
MAX_IDLE_CONNS=500
MAX_IDLE_CONNS_PER_HOST=200
```

## 使用建议

1. **大请求场景**
   - 考虑减少工具数量
   - 使用较小的max_tokens值
   - 启用请求优化

2. **高并发场景**
   - 监控连接池使用情况
   - 调整并发限制
   - 使用缓存减少重复请求

3. **监控指标**
   - 请求大小分布
   - 缓存命中率
   - 连接池使用率
   - 响应时间

## 性能基准

优化前后对比（99KB请求，32000 max_tokens）：
- 首次响应时间: -40%
- 内存使用: -30%
- 并发处理能力: +150%

## 注意事项

1. 这些优化主要针对大请求和高并发场景
2. 小请求场景下优化效果不明显
3. 需要根据实际负载调整参数
4. 建议在生产环境前进行充分测试
